# CS370
<h1>Project Reflection</h1>

<h2>Brief Explanation of the Work Completed</h2>

<p>
In this project, I was provided with starter code that defined the environment and structure of the game, including the maze layout, the TreasureMaze class for handling state transitions and rewards, and the GameExperience class for managing experience replay and Q-value calculations. I was also given a partially completed Jupyter Notebook with placeholders indicating where the training logic for the intelligent agent should be implemented.
</p>

<p>
My primary responsibility was to create the deep Q-learning training algorithm for the pirate intelligent agent. I implemented the logic that resets the environment, selects actions using an epsilon-greedy strategy, stores experiences in replay memory, trains the neural network using sampled experiences, updates the target network, and tracks performance metrics such as loss and win rate. This work required integrating concepts from neural networks, reinforcement learning, and Q-learning into a functional and testable solution that allowed the pirate agent to successfully learn a path to the treasure.
</p>

<h2>What Do Computer Scientists Do and Why Does It Matter?</h2>

<p>
Computer scientists design, analyze, and implement computational solutions to complex problems. Their work ranges from building software systems and algorithms to developing artificial intelligence, managing data, and ensuring systems operate efficiently and securely. This work matters because modern society depends on reliable and ethical computing systems in areas such as healthcare, finance, transportation, communication, and entertainment.
</p>

<p>
In the context of this project, computer science principles enabled the creation of an intelligent agent capable of learning from experience rather than relying on rigid, predefined rules. This type of adaptive problem solving is increasingly important as systems become more complex and dynamic.
</p>

<h2>How Do I Approach a Problem as a Computer Scientist?</h2>

<p>
I approach problems as a computer scientist by first understanding the requirements and constraints of the problem, then breaking it down into smaller, manageable components. I analyze what data is available, what decisions need to be made, and how success can be measured. From there, I select appropriate algorithms or models and iteratively test, debug, and refine my solution.
</p>

<p>
In this project, that approach involved understanding how reinforcement learning works, identifying where learning should occur in the code, and carefully debugging issues related to action selection, training stability, and performance tracking. Iterative testing and analysis were essential to improving the agent’s behavior over time.
</p>

<h2>What Are My Ethical Responsibilities to the End User and the Organization?</h2>

<p>
As a computer scientist, I have an ethical responsibility to design systems that are reliable, transparent, and aligned with the needs of both end users and the organization. This includes ensuring that systems behave as intended, avoiding unnecessary bias, protecting user data, and considering how automated decisions may impact users.
</p>

<p>
Even in a simulated environment like this project, ethical responsibility is reflected in designing an agent that behaves predictably, does not exploit unintended system behavior, and operates within defined constraints. In real-world applications, these responsibilities extend to fairness, accountability, and minimizing harm while maximizing the positive impact of technology.
</p>
